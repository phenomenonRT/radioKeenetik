# 🚀 Быстрый старт radioKeenetik

## ⚡ За 5 минут на Ubuntu 24

### Шаг 1: Установка (2 минуты)
```bash
sudo apt update && sudo apt install -y mpv go-lang git
git clone https://github.com/yourusername/radioKeenetik.git
cd radioKeenetik
```

### Шаг 2: Сборка (1 минута)
```bash
go mod download
go build -o radioKeenetik app.go server.go audio.go
```

### Шаг 3: Запуск (10 секунд)
```bash
./radioKeenetik
```

### Шаг 4: Откройте в браузере
```
http://localhost:8080
```

**Готово! 🎵**

## 📱 Использование

### Добавить станцию
1. Прокрутите вниз до "➕ Добавить станцию"
2. Заполните поля:
   - **Название:** Rock Life
   - **URL:** https://stream.example.com/rock.mp3
   - **Жанр:** Рок
   - **Страна:** Россия
3. Нажмите **Добавить**

### Запустить радио
1. Нажмите **▶️** на станции
2. Регулируйте **🔊 Громкость**
3. Выберите **🎧 Аудиокарту** (если несколько)

### Поиск
- Введите название станции в **🔍 Поиск**
- Результаты обновятся сразу

### Избранное
- Нажимайте **⭐** чтобы добавить в избранное
- Переходите на вкладку **⭐ Избранное** чтобы видеть их

## 🛠️ Если что-то не работает

### Приложение не запускается
```bash
# Проверьте плеер
which mpv

# Если нет - установите
sudo apt install -y mpv
```

### Нет звука
```bash
# Проверьте USB карту
aplay -l

# Если нет - есть проблема с оборудованием
```

### Станции не добавляются
- Проверьте URL (должен начинаться с http:// или https://)
- Откройте DevTools браузера (F12)
- Посмотрите консоль на ошибки

### Невозможно подключиться
```bash
# Проверьте, запущено ли приложение
ps aux | grep radioKeenetik

# Проверьте порт
netstat -tlnp | grep 8080
```

## 🌐 На роутере

### 1. Подготовка бинарника
```bash
# На Ubuntu - собрать для ARM
make build-arm

# Файл: radioKeenetik-arm
```

### 2. Загрузить на роутер
```bash
scp radioKeenetik-arm root@192.168.1.1:/opt/
```

### 3. Запустить на роутере
```bash
ssh root@192.168.1.1
chmod +x /opt/radioKeenetik-arm
/opt/radioKeenetik-arm
```

### 4. Откройте в браузере
```
http://192.168.1.1:8080
```

## ❓ Часто задаваемые вопросы

### Как сохранить станции?
На данный момент станции хранятся в памяти. Перезагрузка сервера их удалит.
**Планируется добавить в будущем.**

### Как использовать на нескольких устройствах?
Просто откройте `http://192.168.1.1:8080` на другом устройстве в той же сети!

### Как ограничить доступ?
Используйте firewall на роутере:
```bash
sudo ufw allow from 192.168.1.0/24 to any port 8080
```

### Как обновиться?
```bash
git pull
make clean
make build
./radioKeenetik
```
