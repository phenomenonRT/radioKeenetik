🐛 ИСПРАВЛЕННЫЕ БАГИ
════════════════════════════════════════════════════════════════════════════

BUG #1: JavaScript синтаксис в Go коде ⚠️ КРИТИЧЕСКИЙ
  Проблема: div.Set("innerHTML", '...') - синтаксис Go в JavaScript!
  Следствие: Приложение падает, станции не загружаются
  Решение: Исправлен на div.innerHTML = '...'
  Файл: main.go (строка ~750) → Исправлено во всех файлах

BUG #2: Клиенты не уведомляются при добавлении ⚠️ КРИТИЧЕСКИЙ
  Проблема: rs.notifyClients() - закомментирована!
  Следствие: Новые станции не видны, нужна перезагрузка страницы
  Решение: Вызов включен в AddStation()
  Файл: main.go (строка ~355) → server.go (AddStation)

BUG #3: Отсутствие модульности ⚠️ АРХИТЕКТУРА
  Проблема: main.go 900+ строк, HTML встроен в Go
  Следствие: Сложно менять, невозможно переиспользовать
  Решение: Разделено на app.go, server.go, audio.go
  Файл: main.go → Переработано в 4 отдельных файла

🚀 КАК ИСПОЛЬЗОВАТЬ
════════════════════════════════════════════════════════════════════════════

БЫСТРО:
  $ make quick-install
  $ radioKeenetik
  # http://localhost:8080

ПОШАГОВО:
  $ go mod download
  $ go build -o radioKeenetik app.go server.go audio.go
  $ ./radioKeenetik

МОНОЛИТ (ОДИН ФАЙЛ):
  $ go build -o radioKeenetik main.go
  $ ./radioKeenetik

DOCKER:
  $ docker-compose up -d
  # http://localhost:8080

НА РОУТЕР (ARM):
  $ make build-arm
  $ scp radioKeenetik-arm root@192.168.1.1:/opt/
