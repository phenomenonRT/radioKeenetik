P: С чего начать?
О: 1. Распакуй архив
   2. Читай INSTALL.txt
   3. Выполни инструкции

P: Какой файл выбрать - app.go или main.go?
О: app.go + server.go + audio.go (модульная версия лучше!)
   main.go - только если нравится всё в одном файле

P: Что требуется?
О: Go 1.21+, mpv, git (опционально)

P: Как установить mpv?
О: Ubuntu: sudo apt install -y mpv

P: Не работает?
О: 1. Читай INSTALL.txt раздел "Помощь"
   2. Проверь логи в терминале
   3. Читай README.md раздел "Решение проблем"

P: Как на роутер?
О: make build-arm
   Затем сохрани radioKeenetik-arm на роутер
   Читай ROUTER_SETUP.md
