🚀 БЫСТРАЯ УСТАНОВКА
════════════════════════════════════════════════════════════════════════════

ШАГ 1: Распаковать архив
  $ unzip radioKeenetik-v2.0.0.zip
  $ cd radioKeenetik-v2.0.0  (или создайте папку и скопируйте файлы)

ШАГ 2: Установить зависимости (Ubuntu 24)
  $ sudo apt update
  $ sudo apt install -y go-lang mpv git

ШАГ 3: Скачать Go зависимости
  $ go mod download

ШАГ 4: Собрать приложение (ВЫБЕРИ ОДИН ВАРИАНТ)

  ВАРИАНТ A - Модульная версия (рекомендуется):
    $ go build -o radioKeenetik app.go server.go audio.go

  ВАРИАНТ B - Один файл (монолит):
    $ go build -o radioKeenetik main.go

  ВАРИАНТ C - С Makefile:
    $ make build
    (или всё в одной команде: make quick-install)

ШАГ 5: Запустить
  $ ./radioKeenetik

ШАГ 6: Открыть в браузере
  http://localhost:8080

🆘 ПОМОЩЬ

ОШИБКА "No such file or directory"
  → Проверьте что все файлы распакованы в одну папку

ОШИБКА "cannot find module"
  → Выполните: go mod download

ОШИБКА "command not found: mpv"
  → Установите: sudo apt install -y mpv

ОШИБКА "permission denied"
  → Дайте права: chmod +x radioKeenetik

ПРИЛОЖЕНИЕ НЕ ЗАПУСКАЕТСЯ
  → Проверьте: ./radioKeenetik (запустите прямо в папке)
  → Смотрите логи в терминале
  → Читайте README.md раздел "Решение проблем"
