3. Заполните форму:
   - Название: Rock Life
   - URL: https://stream.example.com/rock.mp3
   - Жанр: Рок
   - Страна: Россия
4. Нажмите "Добавить"

## 📖 Краткая справка

### Файлы для разных ситуаций

| Ситуация | Используйте | Команда |
|----------|-------------|---------|
| Быстрый старт | app.go + server.go + audio.go | make build |
| Один файл | main.go | go build main.go |
| Docker | Dockerfile | docker build . |
| На роутер | Makefile | make build-arm |

### Команды Makefile

```bash
make help              # Справка
make quick-install     # Всё в одной команде ⭐
make build             # Собрать для Linux
make build-arm         # Собрать для ARM (роутеры)
make build-arm64       # Собрать для ARM64
make run               # Собрать и запустить
make install           # Установить в /opt
make check-player      # Проверить плеер
make check-audio       # Проверить аудиокарты
```

### REST API (основные команды)

```bash
# Список станций
curl http://localhost:8080/api/stations | jq .

# Запустить станцию 1
curl -X POST http://localhost:8080/api/play?id=1

# Остановить
curl -X POST http://localhost:8080/api/stop

# Текущая станция
curl http://localhost:8080/api/current | jq .

# USB карты
curl http://localhost:8080/api/audio-devices | jq .
```

## ❓ Часто задаваемые вопросы

### P: Какой файл выбрать - app.go или main.go?
**О:** Используйте `app.go + server.go + audio.go` (модульная версия) - это лучше!
Если не нравится - используйте `main.go` (монолит).

### P: На каком Go версия работает?
**О:** Go 1.21+. Проверьте: `go version`

### P: Что если нет плеера?
**О:** Установите: `sudo apt install -y mpv`

### P: Как использовать на мобильном?
**О:** Откройте `http://192.168.X.X:8080` в браузере смартфона

### P: Как запустить на роутере?
**О:** Смотрите `ROUTER_SETUP.md` или используйте `make build-arm`

### P: Как обновить проект?
**О:** `git pull && make clean && make build`

### P: Как выложить на GitHub?
**О:** Используйте `bash push-to-github.sh username`

### P: Почему используется темная тема?
**О:** Она лучше для глаз и для роутеров, которые часто находятся в шкафах

### P: Возможно ли добавить свои функции?
**О:** Да! Видите нужное в `server.go` или `audio.go` - добавляйте и меняйте
